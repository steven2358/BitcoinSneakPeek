Bitcoin Sneak Peek Test Page

Testing Tips:
  • Wait at least 3 seconds before clicking the same address again (rate limiting)
  • Test specific providers with modifier keys:
    • Click → Blockchain.com (primary)
    • Shift + Click → Mempool.space
    • Ctrl + Click (or Cmd + Click on Mac) → Blockstream.info
    • Alt + Shift + Click (or Option + Shift + Click on Mac) → BlockCypher
  • Check the browser console (F12) for detailed logs
  • Check the service worker console (chrome://extensions → service worker) for API logs
